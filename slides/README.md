# First Project Presentation

**Google Slides link**: [Presentation](https://docs.google.com/presentation/d/1ErGyQn2MeLaiBF6BBS30fF6zBBgfb0nq/edit?usp=sharing&ouid=103123837645577444399&rtpof=true&sd=true)

`project_presentation.pptx` in this folder is a starting skeleton for that
deck (title, business context, one slide per question with the final
numbers, and a two-part closing with recommendations) -- import it into
Google Slides via File → Import slides to use it as a base, then adjust
freely from there.

`build_deck.js` is the script that generates it (`pptxgenjs`, run with
`node build_deck.js`). Re-run it after editing to regenerate the file from
scratch, rather than hand-editing the `.pptx`.
